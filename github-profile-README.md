# Hi, I'm Bryan Nguyen

I'm a Computer Engineering undergraduate at Virginia Tech, graduating in Spring 2028. I like building practical full-stack tools, automation, and infrastructure that turn messy workflows into reliable software.

Right now, I'm especially interested in API-driven apps, deployment pipelines, and systems that make data or operations easier to access.

## What I'm Working On

- Building full-stack projects with React, Next.js, PostgreSQL, Docker, Tailwind CSS, and Bun.
- Improving my homelab and deployment workflow with containerized apps and GHCR publishing.
